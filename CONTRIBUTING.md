# Contributing

Found a clearer way to explain something? Open a suggestion or pull request.

## Fast path

1. Fork this repository.
2. Create a small branch.
3. Make focused edits.
4. Open a pull request with:
   - what you changed
   - why it helps beginners
   - any tradeoffs or assumptions

## What to optimize for

- Keep guidance generic across macOS, Linux, and Windows.
- Prefer plain language and practical checklists.
- Keep cloud-first and safety-first defaults.
- Mark vendor-specific ideas as optional.

## Security rule

Never commit real secrets, tokens, or live `.env` files.
